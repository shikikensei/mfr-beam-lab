# MFRビームスケジューリング研究室

多機能レーダ（MFR）が、1本のビームの時間を「捜索」と「追尾」でどう取り合うかを、手を動かして確かめるための教育用Webツールです。スケジューリング手法（並べ方）の違いを、スローモーションと負荷の変化で見比べます。

**公開ページ：** https://shikikensei.github.io/mfr-beam-lab/

> **開発中です。** 4章は未完成で、数値・文章・画面は予告なく変わります。

## 前提

- 公開文献の考え方を単純化した教育用モデルです。特定の装置の方式や数値は含みません。
- 画面に出る数値（ドウェルの長さ、更新間隔、探知確率、スラックの幅など）は、説明のために置いたものです。
- 「動的RSI（論文の記述どおり）」は、下記の論文の文章と図を本ツールが解釈して実装したものです。その成績は本ツールの解釈と説明用シナリオでの結果であり、論文の方式そのものの優劣を示しません。
- 「動的RSI＋先読み」は本ツールの拡張で、論文にはありません。
- 「2勾配ベネフィット」は、**原文未確認の要約に基づく実装** です。P. W. Moo の技術報告書（DRDC Ottawa TM 2010-259、2010年）の二次要約から書いたもので、原文と照合していません。原文を確認できていないため、下の参考文献には載せていません。
- モデルが置いた仮定の一覧は [`docs/assumptions.md`](docs/assumptions.md) にあります。

## 内容

| 章 | 内容 | 状態 |
|---|---|---|
| 0 導入 | 時間は1本しかない | あり |
| 1 しくみを知る | 目標の一生、要求の一生、箱の組み立て（1手ずつ）、従来型との比較、特別な場面 | あり |
| 2 負荷を上げて確かめる | 目標が増えていく60秒間を、1秒ごとに見る | あり |
| 3 手法を比べて考える | 同じ状況に10の並べ方を当てる | あり |
| 4 配り方を考える | 並べる前に、何をどれだけ頼むかを決める層 | 準備中 |
| 5 前提と文献 | モデルの仮定と文献 | 書きかけ |

## ローカルで動かす

Node.js 24 で確認しています。

```sh
npm install
npm run dev    # 開発サーバ。表示されたURLをブラウザで開く
npm test       # エンジンのテスト
npm run build  # dist/index.html を1ファイルで出力
```

計算はすべてブラウザ内で行います。サーバは不要です。

## 構成

- `src/engine/`：シミュレーションのエンジン（画面に依存しない純粋な関数とテスト）
- `src/ui/`：描画と文言
- `scripts/`：検証用のスクリプト。`docs/assumptions.md` に載せた数値の出どころです（`node scripts/<名前>.ts` で実行）
- `docs/assumptions.md`：モデルの仮定、論文が決めていない点の埋め方
